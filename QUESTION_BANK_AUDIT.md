## Pipeline verification

1. **Rows → questions:** `rowsToQuestions()` in `messer/loadMesserMcq.ts` sets `correctIndices` for array `correct` values.
2. **Merged into `quizQuestions`:** Messer questions appended after curriculum merge with **id deduplication** (skip if id already present).
3. **`questionsByLesson(id)`:** Returns Messer bank for `messer-exam-a` | `b` | `c`.
4. **Practice routes:** `/quiz/messer-exam-a` (etc.) with `?mode=exam|study` and `?wrongOnly=1` for last attempt misses.
5. **Multi-select:** `QuizPage` uses toggle + submit (study) or Next (exam); grading uses set equality on sorted indices.
6. **Explanations:** Messer `explain` → `QuizQuestion.explanation`; shown after each question (study) or on review (exam).
7. **Weak areas / flashcards:** `recordQuiz` → `addMiss` + optional auto user flashcard (`ProgressContext`); `correctAnswerLabel` fixes multi-select card backs.
8. **Lesson quizzes:** Unchanged; still complete `patchLessonProgress` on last lesson question.
9. **Duplicate IDs:** `validate-app-data.ts` fails on duplicate question ids globally and duplicate Messer row ids across banks.
10. **Malformed rows:** If any row lacks `id`, `options`, or `correct`, TypeScript/build fails; fix in data (do not delete questions).
