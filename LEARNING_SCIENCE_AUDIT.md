# Learning science audit

## Principles present

| Principle | Where it shows up | Strength |
|-----------|-------------------|----------|
| **Active recall** | Quizzes, boss fights, teach-back prompts, flashcards | **Strong** |
| **Spaced repetition** | Spaced queue + flashcard scheduling | **Strong** |
| **Retrieval practice** | Session 30 phases, quick quizzes | **Medium–strong** |
| **Feedback loops** | `feedbackLoop`, false-confidence tracking, progression pause | **Strong** |
| **Mistake-based learning** | Miss journal → weak page → flashcard generation | **Strong** |
| **Metacognition** | Confidence selector before advancing | **Medium** |
| **Cognitive load reduction** | Beginner mode, guided watch chunks, simple explanations | **Medium** (lesson page still heavy) |
| **Interleaving** | Mixed exams, search jumps | **Weak–medium** (default path is blocked lessons) |
| **Transfer to scenarios** | Labs/sims, boss narratives | **Medium** |

## Weak areas

- **Interleaving** — Main path is sequential; optional mixed review would strengthen discrimination learning.  
- **Calibration** — Confidence is captured but not visualized as “well calibrated vs overconfident” over time.  
- **Desirable difficulties** — Some users may lean on repeated study mode; exam mode needs stronger nudges.

## Does it teach or just display?

**Teaches** — Explanations, traps, coaching text, and adaptive feedback go beyond content display. The risk is **passive video watching** if users skip quizzes; the app mitigates with coach + daily minimum but cannot force effort.

## Recommendations

1. **Weekly mixed review** deck (10Q across domains) — medium effort, high learning ROI.  
2. **Calibration chart** — confidence vs outcome by domain (small feature, big insight).  
3. **Load shedding** — collapse training blocks until quiz attempted once.

## Score (study effectiveness)

**83/100** — Solid retrieval + feedback architecture; interleaving and load management are the growth edges.
