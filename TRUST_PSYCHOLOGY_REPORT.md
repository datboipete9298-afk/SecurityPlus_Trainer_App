# TRUST + PSYCHOLOGY REPORT

---

## Signals that build trust (present)

- **Local-first:** repeated export/import + “nothing uploads unless you…” narrative.
- **No shame framing on wrong answers** in tutor feedback pathways (quiz engine — spot-check wording in `FeedbackPanel` / stickers).
- **Continue without blocking:** HomeGate doesn’t jail users in Start Here.
- **Transparency on AI:** Live vs limited vs offline badges; fallback structure instead of blanks.

---

## Signals that erode trust (risk areas)

| Risk | Psychological effect |
|------|------------------------|
| Busy dashboard | Mild anxiety (“am I behind?”) |
| “Live AI” then instant offline | Mild skepticism — mitigated if badge accurate on first paint |
| Quiz refresh surprise | Feels like data loss even if stats retained |
| Multi-tab | Corruption fear if user sees inconsistent counts |

- Copy tends **coach-y** not **punitive** — aligns with adult self-efficacy.
