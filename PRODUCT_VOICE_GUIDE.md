# Security+ Trainer — product voice

**Product promise (use verbatim when a single line is needed):**

> Security+ study that tells you exactly what to do next.

**Supporting line (optional, e.g. Start here / first loop):**

> Watch, write, check, and keep moving.

---

## Tone

- **Calm** — no alarmist copy; exams are serious, not scary.
- **Direct** — short sentences; say what the UI does.
- **Encouraging** — progress is data; misses are repair opportunities.
- **Serious** — Security+ prep, not entertainment.
- **Never childish** — no gamespeak, ranks, or fake cheer.
- **Never hype-heavy** — no “crush it,” “dominate,” or score bragging.

---

## Preferred phrases

| Use | For |
|-----|-----|
| Do this next | Primary action strip, mobile sticky CTA framing |
| Pick up where you left off | Resume links, session restore |
| Save it to Brain Book | Note capture (synonym: “Save to Brain Book” on buttons) |
| Check understanding | Quick checks, quizzes as retrieval |
| Repair this miss | Wrong answers, weak-area actions |
| This shows where to study next | Scores, readiness, practice exams |
| Lesson path | Ordered curriculum (Messer order in app) |
| Professor Messer videos | External video source (proper noun) |
| PDF study guides | Registry / official-style PDF slots |
| My PDFs / your PDF library | User-imported text (local only) |
| Weak areas | Hub for misses and domain repair (same as “repair queue” in tone) |
| Practice exams | Timed A/B/C and hub |
| Elite SOC labs | Hands-on triage blocks (keep “Elite” — product term) |
| Built-in coach | Offline / rule-based tutor when AI is unavailable |

---

## Avoid

| Avoid | Prefer |
|-------|--------|
| Generic “Continue” / “Submit” as the *only* label | Action-specific labels; strip already says **Do this next** |
| Harsh “Incorrect” alone | “Not quite — …” + fix path |
| Vague “study more” | Named surface: lesson path, repair queue, flashcards |
| Hype (“smash the exam,” “guaranteed pass”) | Readiness is a **practice signal**, not CompTIA scoring |
| “The AI will…” as mandatory | **AI is optional**; core flows work with built-in coach |

---

## Trust (keep short; repeat where users commit data)

- **PDFs stay on this device** until they choose to move them.
- **Progress is local** unless exported (Progress → backup).
- **Readiness** reflects in-app practice — not official cut scores.
- **Optional AI**; structured built-in coach when the API is off.

---

## Final line (internal north star)

**Calm. Clear. Serious. Helpful. Built to keep me moving.**
